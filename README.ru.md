# Voice Island

Голосовой ввод для Linux с компактным виджетом в стиле Dynamic Island.
Проект вырос из инструмента, которым автор давно пользуется в повседневной работе.

[English](README.md) · [Установка](docs/INSTALL.md) · [Планы доступности](ROADMAP.md)

![Предпросмотр Voice Island с синтетическим сигналом](docs/images/preview.png)

Нажмите горячую клавишу, произнесите текст и нажмите её ещё раз. Приложение
отправит запись выбранному вами сервису распознавания и вставит результат.
Виджет показывает запись и обработку, после завершения исчезает.

Сейчас работают:

- запуск и остановка одним нажатием, без удержания клавиши;
- пять цветовых тем и четыре вида анимации;
- горячая клавиша средствами рабочего стола;
- вставка текста либо копирование в буфер обмена;
- отмена и ограничение длительности записи;
- защита от вставки в другое окно, если фокус сменился во время обработки.

Нужны **Linux/X11**, GTK 3, PulseAudio или совместимый сервис PipeWire,
`parec`, `xdotool` и отдельный HTTP-сервис распознавания. Модель не встроена
в клиент. Для начала можно посмотреть виджет без микрофона:

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 python3-numpy python3-requests pulseaudio-utils xdotool
git clone https://github.com/up4k73/voice-island.git
cd voice-island
./bin/voice-island --preview
```

После настройки [сервиса распознавания](docs/BACKEND.md):

```bash
./bin/voice-island --url http://127.0.0.1:9875/transcribe
```

Назначьте в настройках горячих клавиш рабочего стола команду с полным путём:
`/путь/к/voice-island/bin/voice-island --toggle`. Для отмены есть `--cancel`,
для выхода — `--quit`. Настройки создаются командой `--init-config`.

Если во время распознавания переключиться в другое окно, текст попадёт в
буфер обмена, а виджет сообщит об этом. Клиент не хранит записи и не пишет
распознанный текст в журнал. Отдельный сервис распознавания настраивается самим
пользователем.

По умолчанию результат вставляется через буфер обмена и Ctrl+V, чтобы не терять
кириллицу при смене раскладок. Для терминала укажите `paste_shortcut`:
`ctrl+shift+v` в настройках. Содержимое буфера при диктовке заменяется.

В дальнейшем планируются голосовые команды, альтернативные кнопки запуска,
звуковое подтверждение состояния и более гибкие настройки интерфейса для
людей с ограничениями моторики или зрения. Эти функции описаны в [плане
развития](ROADMAP.md); они не выдаются за уже реализованные.
